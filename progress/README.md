# SAHF_Net 项目进度

先读 [STATUS.md](STATUS.md) 了解项目现状，再按文件名日期查阅 `runs/` 中最近的 JSON。文件名使用 UTC，每次调用 `main.py` 生成一条记录。训练摘要包括运行编号、模型、配对模式、种子、运行签名和最佳验证 IoU。完整训练记录见 JSON 中的项目相对输出路径。

`running` 表示已启动且尚未写入结束状态。遇到强制终止或机器掉电时，记录可能停留在该状态，请核对实际进程和输出。失败记录保存异常类型，详细原因以服务器终端或实验日志为准。

项目在服务器运行，记录也在服务器生成。提交 GitHub 前把服务器的 `SAHF_Net/progress/runs/` 下载到本地同名目录，并提交 `progress/`。JSON 不复制命令原文、绝对路径、数据或权重。
